# 29. Data Architecture

Even if there is no backend right now, structure the application as if an API will be connected later.

Create centralized configuration/data files.

For example:

```text
src/
  components/
  sections/
  pages/
  data/
    services.js
    cities.js
    testimonials.js
    staff.js
    faqs.js
  config/
    business.js
  hooks/
  utils/
```

Do NOT hardcode business information throughout components.

Create something like:

```js
export const businessConfig = {
  name: "Care Crew Maid",
  phone: "+92XXXXXXXXXX",
  whatsapp: "923XXXXXXXXXX",
  email: "info@example.com",
  cities: [
    "Islamabad",
    "Rawalpindi",
    "Lahore",
    "Karachi"
  ]
};
```

This allows the owner to change details easily.
